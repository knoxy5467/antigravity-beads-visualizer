# Antigravity Beads Visualizer

Read-only Antigravity plugin and standalone viewer for Beads meta-epics, sub-epics, dependency graphs, gates, and workflow lanes.

## Features

- **Nested Epic Tree:** Inspect recursive meta-epics, sub-epics, tasks, priority tags, and completion bars.
- **Dependency Graph:** Trace `blocks`, `parent-child`, `discovered-from`, and `relates-to` links.
- **Issue Inspector:** Read descriptions, acceptance criteria, six-key notes, comments, and spec references.
- **Standalone & Test Mode:** Run locally over `bd` JSON or in synthetic fixture mode (`BEADS_TEST_ENV=synthetic`) for Playwright verification.
